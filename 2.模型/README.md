# 数据编码与模型部分

`ma_tgn/` 是不包含训练流程和数据文件的核心模型包。

| 文件 | 作用 |
| --- | --- |
| `state_schema.py` | 状态字段、单位、归一化尺度与置信度约定 |
| `types.py` | 图事件、查询图、任务、训练样本以及稳定的事件/关系编码 |
| `config.py` | 模型维度、关系类型和实验开关 |
| `capabilities.py` | 动态能力槽、能力拆分和逐能力可靠性 |
| `encoders.py` | 智能体、算力节点、边、时间和任务编码器 |
| `attention.py` | 任务条件化的异构关系注意力 |
| `memory.py` | 快、慢双时间尺度节点记忆 |
| `model.py` | MA-TGN 主模型、事件更新、查询和 Top-K |
| `__init__.py` | 对外公开的模型接口 |

依赖方向保持单向：数据与训练可以依赖模型，模型不读取具体数据集，也不写训练产物。
