# 四图性能仿真协议（V5）

## 实验设置

- 方法：Ours (DAG-GRU)、GMATANN、Rule-Latency、State-MLP、StaticGraph、GRU-Minimal。
- 训练：随机种子 7、17、29；每个可训练方法 8 epoch。
- 划分：54/9/9，时间不重叠，并覆盖 3 场景 × 3 难度。
- 图规模：50、100、200、400、800、1600 个智能体节点。物理系统仍允许两两通信，GNN 计算图采用固定 fanout=4 的邻居采样，避免把 1600 节点完全图的约 256 万条边当作常规训练输入。
- 并发任务：1、2、4、8、16、32、64，全部使用中等难度任务。相同智能体每多一个任务，执行时间增加 15%；相同算力节点每多一个任务，再增加 6%。

只保留四幅论文图：

1. 场景 × 难度完成准确率（分面柱状图）；
2. 场景 × 难度 DAG 完成时延（分面柱状图）；
3. 图规模—完成准确率/时延曲线；
4. 并发任务数—完成准确率/时延曲线。

可靠任务完成率、归一化后悔值和 deadline miss 已从计算、CSV、汇总与绘图代码中移除。

## 指标

- 完成准确率：各子任务所选智能体的 `成功率 × (1 - 幻觉率)` 均值；并发过载导致的超时/中断尝试按 0 分折算。
- DAG 时延：平均执行时间、智能体—算力通信时延、前驱—后继通信时延和并发等待共同决定的关键路径时延。

## 正式结果

| 方法 | 完成准确率 | DAG 时延 (s) |
| --- | ---: | ---: |
| Ours (DAG-GRU) | 85.63% | 26.54 |
| GMATANN | 86.00% | 26.81 |
| Rule-Latency | 85.23% | 26.75 |
| State-MLP | 86.01% | 26.89 |
| StaticGraph | 86.09% | 26.41 |
| GRU-Minimal | 85.26% | 26.60 |

这批结果不支持“主模型在所有指标全面最优”。主模型时延优于 GMATANN、规则、MLP 和最小状态消融，但 StaticGraph 在当前小样本、偏静态 teacher 标签下仍更好；准确率最高的是 StaticGraph。预设算法名次不能写进仿真器，后续应通过更多动态扰动样本、真实执行日志和 DAG 级联合解码检验研究假设。

产物位于 `outputs/paper_simulation_v5/`，包括 4 幅 PNG、4 份矢量 PDF、逐样本 CSV、checkpoint、训练历史和协议摘要。入口为 `experiments/run_paper_simulation.py`。
