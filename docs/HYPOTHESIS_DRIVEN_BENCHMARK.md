# 假设驱动的可辨识压力基准

## 为什么原实验无法区分模型

原始 72 个复杂任务包含 351 个子任务，其中 200 个子任务在精确 Skill 筛选后只有一个候选，占 56.98%；平均合格候选只有 1.61 个。与此同时，训练损失只监督 `dag_current_index` 指向的一个子任务，而推理指标却评估整个 DAG。因此六种方法经常被迫选择同一个智能体，结果接近并不能证明模型能力接近。

## 新协议

1. 同一智能体类型的实例共享完整能力卡。
2. 每个样本包含 48 个候选；每个子任务有 4–5 个精确 Skill 合格候选，唯一候选比例为 0%。
3. 训练时对 DAG 每个子任务计算分类和 teacher 分布损失。
4. Teacher 同时使用可靠性、执行时间、三项算力剩余、四项链路状态、未完成任务、邻居压力和历史变化趋势；对所有方法使用同一规则。
5. Ours 使用 DAG 联合解码，根据任务 QoS、模型预测状态和注意力选择智能体，并惩罚同一并行层争用同一智能体或算力节点。其他单子任务方法保持独立选择，这是被比较算法的结构差异，不是结果后处理惩罚。
6. DAG 时延按关键路径计算，并串行化被重复占用的智能体和算力节点。
7. 图规模仍为 50/100/200/400/800/1600；并发任务仍为 1/2/4/8/16/32/64，且均为中等难度。

## 三随机种子正式结果

| 方法 | 完成准确率 | DAG 时延 (s) |
| --- | ---: | ---: |
| Ours (DAG-GRU) | 89.57% | **30.35** |
| GMATANN | **90.21%** | 36.11 |
| Rule-Latency | 84.62% | 34.84 |
| State-MLP | 89.26% | 35.80 |
| StaticGraph | 88.44% | 34.88 |
| GRU-Minimal | 88.12% | 34.64 |

新基准已经产生可辨识差异：Ours 的 DAG 时延比次优方法降低约 12.4%，规则方法准确率最低，GMATANN 保持很强的单子任务选择准确率。结果不完全符合预设全序，因此不能声称“所有排序假设均验证”。特别是，GMATANN 的准确率略高于 Ours，说明当前联合解码为了降低 DAG 时延产生了准确率—时延权衡；GRU-Minimal 的时延优于 Rule/Static/MLP，说明轻量状态在本压力集上仍有价值。

不得在观察结果后通过算法名称惩罚、手工改 CSV 或选择性删除随机种子来制造目标排序。如果论文需要验证每个模块，应报告候选可辨识性审计、三随机种子均值和误差棒，并把预设排序写成待检验假设而不是结果约束。

数据位于 `1.data/datasets/sixg_ma_state_stress/`，结果位于 `outputs/hypothesis_stress_v1/`，入口仍为 `experiments/run_paper_simulation.py`。
