# 论文图构建与特征融合实现说明

## 1. 可复现边界

论文明确给出了 VAE 目标、注意力式(2)–(5)、两类节点、全局/局部两条支路和特征融合顺序，但没有给出隐藏维度、层数、具体条件向量、边特征维数、训练批大小等完整超参数。正文还沿用了“图像、通道、1×1 卷积”等视觉任务表述。这里复现论文能确定的计算结构；未公开的选择全部放在 `GCANConfig` 中，并采用适合 LLM 智能体状态向量的等价实现。

## 2. 输入和 task-agent 图

每条 JSONL 记录只取当前子任务，不读取 `dag_*` 字段。局部节点编号为 `[0, ..., N-1, N]`，其中前 `N` 个是候选智能体，最后一个是当前任务。

三类有向边：

1. `task -> agent`：任务要求向候选传播；
2. `agent -> task`：候选状态向任务节点汇聚；
3. `agent -> agent`：来自查询图中候选之间的通信/协作关系。

task-agent 边包含 Skill 可执行性、任务/能力文本相似度和 QoS；agent-agent 边包含时延、带宽、丢包、抖动、置信度和状态年龄。关系嵌入与边特征同时进入图注意力的 key、value 和 bias。

## 3. 时间序列条件变分自编码器

`data.py` 按时间戳重放事件，为每个候选形成 `[T, 24]` 的观测序列，包含上下文、运行环境、逐能力可靠性池化、算力负载和链路状态。不同长度以 mask 对齐，损失只计算真实观测位置。

条件向量由“候选能力文本 + 当前任务向量”生成，既进入编码器的每个时间步，也与潜变量共同进入解码器。编码器输出高斯后验的 `mean` 与 `log_variance`，训练时执行重参数化：

```text
z = mean + exp(0.5 * log_variance) * epsilon
```

双向 LSTM 对应论文所述的时序重排/循环处理；条件 LSTM 解码完整历史序列。训练目标包含掩码 MSE 重构项和 KL 散度项，对应论文式(1)。

## 4. 图注意力与全局-局部融合

首先用多层关系图注意力在 task-agent 图上传播。随后对同一节点表示分别计算：

- 局部注意力：softmax 只允许直接相邻节点和自身；
- 全局注意力：softmax 可读取图中所有节点。

两条支路都实现缩放点积 `softmax(QK^T / sqrt(d_k))V`，并按论文式(5)执行 `delta + tau * attended_value`；`tau` 是每条支路独立学习的参数。最后通过两分支门控加权，再使用 MLP 深层融合，得到最终节点表示。

## 5. 分配头和训练目标

候选分数由“候选融合表示、任务融合表示、二者逐元素交互”共同计算。缺少必需 Skill 的候选在 softmax 前被硬掩码。训练仍使用现有监督标签、候选状态辅助目标和 teacher score 蒸馏；CVAE 的 KL 与重构损失作为辅助项。

该分配头是监督学习基线，不包含 DQN、actor-critic、奖励函数或策略更新，因此满足“不实现论文强化学习部分”的边界。

## 6. 与 LLM 多智能体场景的必要适配

论文只有 AAV/UGV/USV 三类标签，LLM 智能体却由模型、Skill、工具/API、知识库、上下文窗口和运行环境共同定义。固定三类 one-hot 条件无法表达这种异构性，因此实现用候选能力文本嵌入作为细粒度条件，并保留 agent/task 两类节点嵌入。这是场景适配，不改变 CVAE、图注意力或全局-局部融合的论文结构。
